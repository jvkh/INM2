## Ziele

Anhand der geloggten Zugriffsdaten auf den Server sollen Verhaltensweisen von Clients dargestellt werden, die auf den Server zugegriffen haben. Hierbei sollen einige Statistiken dargestellt werden:
- Anzahl Zugriffe, getrennt nach schreibend oder lesend oder andere, pro Zeitintveral in Form einer Balkengrafik anzeigen. Ein Balken pro Stunde.
- Darstellung von Bursts, d.h. ein Akteur startet diverse Zugriffe auf den Server. Hier wird der Zeitraum vom ersten bis zum letzten Zugriff betrachtet. Anhand eines konfigurierbaren Zeitraums werdem Bursts unterschieden.
    - Balkengrafik mit Anzahl der verschiednen Kategorien.
    - Gesamtzahl der Zugriffe
    - Zugriffe pro Sekunde/Minute/Stunde
- Anzahl verschiedener Akteure in einem Zeitraum
